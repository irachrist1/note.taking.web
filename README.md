# note.taking.web

Browser-based note taking app in vanilla HTML, CSS, and JavaScript — early front-end exercise.

## The problem

You are learning localStorage, DOM editing, and list UIs without a framework in the way.

## What it does

Create, edit, and persist notes in the browser — `index.html`, `script.js`, and `style.css`.

## Install

```bash
git clone https://github.com/irachrist1/note.taking.web.git && cd note.taking.web
open index.html
```

## How it works

- **localStorage persistence.** Notes survive refresh — first taste of client-side storage.
- **DOM list rendering.** Add/remove note cards dynamically — fundamental UI pattern.
- **Vanilla stack.** Three files, full visibility — learning exercise, not a Notion competitor.
